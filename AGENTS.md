# Regras do site ANIM4LL

- Leia docs/site-brief.md antes de alterar o site.
- Preserve a direção aprovada: fotografia autoral, clareza, acabamento, acessibilidade e velocidade.
- Mantenha HTML e CSS estáticos. Acrescente dependências ou efeitos somente com necessidade concreta.
- Preserve os materiais originais; use derivados otimizados para a web.
- Não invente clientes, depoimentos, resultados, preços, serviços, autoria ou contexto de projetos. Registre conteúdos ausentes como pendências no briefing.
- Verifique celular e desktop, navegação por teclado, contraste, links e recursos locais. Não afirme que existe build ou suíte de testes quando não houver.
- Não publique em produção sem autorização explícita.
